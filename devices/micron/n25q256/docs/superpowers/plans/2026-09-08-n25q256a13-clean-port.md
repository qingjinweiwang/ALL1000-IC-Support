# N25Q256A13 Clean Driver Port Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild the ALL-1000 Gang4 driver for Micron N25Q256A13 from the PY25Q01GLC transport/task architecture while using only N25Q256A13-valid commands and datasheet parameters.

**Architecture:** Keep the legacy three-file driver interface and 13-callback ABI. Implement device-independent Gang4 SPI primitives first, then build Main Flash, Status/Protection, and OTP task flows on those primitives. Enter volatile 4-byte address mode once at power-on and use standard address-bearing commands with four address bytes.

**Tech Stack:** ARM RVCT C, ALL-1000 firmware ABI, FPGA Gang4 SPI registers, PowerShell static checks, existing `iBuild.bat` RVCT link flow.

## Global Constraints

- Support only Micron N25Q256A13 feature-set-1 devices in Extended SPI.
- Do not use A83-only opcodes `13h`, `12h`, `21h`, or `DCh`.
- Do not read or write NVCR with `B5h` or `B1h` and do not recover abnormal Dual/Quad/XIP startup states.
- Main Flash is 32MB at `00000000h-01FFFFFFh`; page size is 256 bytes.
- Protect and Unprotect use Status Register RMW with fixed mask `0x7C` and preserve all other bits.
- OTP is exactly 64 data bytes plus control-byte bit 0 at offset `40h`; transport padding is never logical data.
- Program and OTP Program reject FSR mask `0x12`; erase rejects FSR mask `0x22`.
- `B7h` uses `06h -> WEL check -> B7h -> FSR bit0 check`, without `50h` or WIP polling.
- Normal writes use `50h -> 06h -> WEL check -> command -> WIP poll -> FSR check -> optional readback`.
- Do not run Git staging, commit, reset, amend, checkout, or other history/index operations.

- [x] **Step 2: Implement four-byte address and register reads**

`Send4ByteAddress()` sends `MSB(MSW(Address))`, `LSB(MSW(Address))`, `MSB(LSW(Address))`, and `LSB(LSW(Address))`, with `SPIRWDelay()` after every byte. Register read helpers own CS for one transaction and always deassert it before returning.

- [x] **Step 3: Implement Gang4 comparisons**

`CheckAllStatusData(expected)` and `CheckAllFlagStatusData(expected)` clear `GClrPageChkStatus`, clock one expected byte through `GDevChkDataLoInc0`, read `GChkAllSckStatus`, and close CS. The caller sets `GSetAllMaskDataLo` before invoking them.

- [x] **Step 4: Implement write helpers**

`WriteStatusWELBit()` sends `06h`, masks SR with `0x02`, and retries for a bounded interval. Partial failures call `GangCheckIfAllSocketError()` and restore the surviving-socket mask. `PollStatusWIP()` masks SR with `0x01`, waits using the supplied count and delay scale, and returns failure for sockets still busy at timeout. `CheckOperationFlags()` applies only the caller-supplied FSR error mask.

- [x] **Step 5: Implement the B7 exception**

```c
uChar Enter4ByteAddressMode(void)
{
    uChar StatusData;

    if (!WriteStatusWELBit())
        return FAIL;

    PtrData(SetCSPinCmd) = 0;
    Delay_10nsX(10);
    PtrData(OneDataCmd) = Enter4ByteAddrModeCmd;
    SPIRWDelay();
    PtrData(SetCSPinCmd) = 1;
    Delay_10nsX(10);

    PtrData(GSetAllMaskDataLo) = FlagStatusAddressModeBit;
    StatusData = CheckAllFlagStatusData(FlagStatusAddressModeBit);
    if (StatusData && GangCheckIfAllSocketError(StatusData))
        return FAIL;
    PtrData(GEnSelSckNum) = (uChar)(~GangErrSckMask);
    Delay_10nsX(3);
    return SUCCESS;
}
```

Do not call `ClearFlagStatusData()` or `PollStatusWIP()` from this helper.

- [x] **Step 6: Implement power entry points and parameter loading**

`PowerOnFun()` performs the template voltage sequence, calls `GetDeviceParameterInfo()`, restores the passing-socket mask, calls `Enter4ByteAddressMode()`, maps failure to `E_AutoIDFail`, and returns. `PowerOffFun()` uses the reference power-down order.

### Task 5: Implement the 65-Byte OTP Task Model

**Files:**
- Modify: `WAx4_N25Q256Ax3ESFxxx/WAx4_N25Q256Ax3ESFxxx.c`

**Interfaces:**
- Consumes: Task 2 write/status helpers and SRAM[3] task-control bits.
- Produces: `SkipOTPBlockData`, `ReadOTPArrayData`, `ProgramOTPArray`, `VerifyOTPArray`, and OTP branches in Read/Program/Verify/BlankCheck/Checksum.

- [x] **Step 1: Define OTP constants and controls**

```c
#define OTPProgramOn       0x01
#define OTPVerifyOn        0x02
#define OTPBlankCheckOn    0x08
#define OTPChecksumOn      0x10
#define OTPDataSize        64
#define OTPControlAddr     0x40
#define OTPBlockSize       65
#define OTPControlMask     0x01
```

- [x] **Step 2: Implement exact logical transport accounting**

`SkipOTPBlockData()` calls `CFCardReadWordData()` 33 times, subtracts 65 from `DramBufCnt` and `DevCurrBlkLen.all`, adds 65 to `DeviceAddress`, and calls `GetChkBlkLenEnd()`. The high byte of word 33 is discarded.

- [x] **Step 3: Implement OTP Read and Verify primitives**

Each `4Bh` transaction sends four address bytes and one dummy byte. Read the 64-byte data area and control byte in separate transactions. `VerifyOTPArray()` uses the Gang4 FPGA compare path, applying mask `FFh` to data and `01h` to the control byte.

- [x] **Step 4: Implement OTP Program with verify-before-lock**

Load 32 words into the 64-byte data buffer, then load word 33 and keep only its low byte as `OTPControlData`. If OTP Program is enabled:

1. Program 64 bytes at offset zero using normal write preparation and `42h`.
2. Poll and check FSR `0x12`.
3. Verify all 64 data bytes.
4. If `(OTPControlData & 0x01) != 0`, send no command to offset `40h`.
5. Otherwise program one byte `FEh` at offset `40h`, poll/check again, and verify control bit 0 only.

- [x] **Step 5: Implement OTP task gates**

Read is unconditional. Disabled Program and Verify consume 33 words through the skip helper. Disabled Blank Check advances only logical device address and remaining length because it has no CF input. Disabled Checksum consumes 33 words without changing the checksum. Enabled Checksum sums exactly 65 low-level logical bytes, excluding the final high-byte padding.
